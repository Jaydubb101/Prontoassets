# Pronto Chat Assets

Static assets for the Pronto embedded messaging deployment.

## Salesforce Image URLs

After this folder is pushed to a public GitHub repository, use the jsDelivr URL format in Salesforce:

```text
https://cdn.jsdelivr.net/gh/<github-user-or-org>/<repo-name>@main/chat/pronto-chat-logo.png
```

Use this file for:

- Bot and AI Agent Avatar
- Logo

Then save and republish the embedded deployment.
